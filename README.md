# Тренажёр системного аналитика

Симулятор рабочего дня системного аналитика: с 09:00 до 18:00, с задачами от руководителя, Product Owner и техлида, стендапом, обедом, встречами, прерываниями и отчётом руководителю. Работает целиком в браузере, без сервера.

## Что внутри

- **Рабочий день.** План на день, тикеты SA-xxx с ревью, возврат на доработку, сообщения в рабочем чате, письменные стендап и отчёт руководителю. По понедельникам планирование спринта, по пятницам ретро.
- **Практика.** SQL с реальным выполнением запросов (sql.js), включая оконные функции, CTE и грязные данные. Диаграммы в Mermaid с живым рендером. Спецификации OpenAPI с валидацией. Кейсы, ревью чужой документации, тесты.
- **Сквозной проект.** «Онлайн-запись в клинику», 10 этапов от целей до пилота.
- **ИИ-наставник (по желанию, свой ключ Anthropic API).** Ревью решений, интервью с заказчиком, который скрывает факты, пробное собеседование, разбор вакансии.
- **Измерение роста.** Ежемесячный контрольный ассессмент, графики результата и скорости, матрица компетенций Junior / Middle / Senior.
- **Отчётность.** Ежедневные, недельные и месячные отчёты в Markdown или PDF. Портфолио для GitHub.

## Запуск

Откройте `index.html` в браузере или опубликуйте через GitHub Pages (Settings → Pages → ветка `main`).

Прогресс хранится в `localStorage` браузера. Для переноса на другое устройство используйте экспорт и импорт резервной копии.

## ИИ и приватность

Ключ API вводится во вкладке «Настройки» и хранится только в вашем браузере. Запросы уходят напрямую в API Anthropic. Рекомендуется отдельный ключ с лимитом расходов.
